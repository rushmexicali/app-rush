# RUSH Car Wash — pantallas

Las tres pantallas de la operación, servidas por GitHub Pages:

| | |
|---|---|
| **Supervisor** | https://rushmexicali.github.io/app-rush/ |
| **Caja** | https://rushmexicali.github.io/app-rush/caja.html |
| **Reporte** | https://rushmexicali.github.io/app-rush/reporte.html |

Las tres piden un código de acceso. Este repositorio contiene **sólo** los archivos que el
navegador necesita; el resto del proyecto —código de servidor, migraciones, pruebas y
documentación— vive en un repositorio privado.

> Este repositorio es público porque GitHub Pages lo exige en el plan gratuito. Por eso **no
> debe entrar aquí ningún dato de personas**: ni nombres de clientes o de empleados, ni placas.
